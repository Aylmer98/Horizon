## [Kimi K3：采用 Delta 注意力与分位数平衡的开源权重模型](https://www.reddit.com/r/MachineLearning/comments/1vaysjf/how_kimi_k3_engineered_its_way_to_the_frontier_r/) ⭐️ 9.0/10

Moonshot 发布了开源权重模型 Kimi K3，在 Artificial Analysis 排行榜上位列 580 个模型中的第四名，仅次于 Claude Opus 5、Fable 5 和 GPT-5.6 Sol。该模型引入了三项创新：Delta 注意力机制（在 93 层中的 69 层替换了 KV 缓存）、用于专家混合负载均衡的分位数平衡，以及用于强化学习训练的 Firecracker 微虚拟机运行时 AgentENV。 Kimi K3 证明了开源权重模型能够在显著提升效率的同时达到前沿性能，挑战了专有模型的主导地位。其在注意力和专家平衡方面的创新可能会影响未来大语言模型的架构设计，并降低长上下文任务的推理成本。 Delta 注意力机制用每个注意力头一个 128x128 矩阵替换了 KV 缓存，将 1M token 上下文的显存占用从 104.6 GiB 降至 27.2 GiB。分位数平衡直接从单个批次的 router 分数边界计算偏置，使得每层支持 896 个专家，避免了 DeepSeek-V3 固定步长偏置调整所遇到的负载不均衡问题。AgentENV 创建了 5100 万个沙箱，检查点耗时 133 毫秒，恢复耗时 49 毫秒，使得 RL 轨迹在模型思考时可以免费暂停。

reddit · r/MachineLearning · /u/noninertialframe96 · 7月30日 16:37

**背景**: 大语言模型依赖注意力机制，其复杂度随上下文长度呈二次增长，导致长序列下显存占用高；KV 缓存存储中间键和值以加速推理。专家混合（MoE）模型每层使用多个专家子网络，并由路由器激活其中一部分，但专家间的负载均衡对效率至关重要。大语言模型的强化学习训练通常需要隔离环境来运行智能体轨迹，这往往成本高昂且缓慢。

## [AI 发现 NIST 后量子候选算法 HAWK 严重弱点](https://startupfortune.com/claude-mythos-broke-hawk-and-the-nist-post-quantum-timeline-may-not-survive-it/) ⭐️ 9.0/10

Anthropic 的 Claude Mythos Preview 模型在约 60 小时内发现了 NIST 后量子密码候选算法 HAWK-256 的严重弱点，将其有效密钥强度从 2^64 降至 2^38。该发现耗费约 10 万美元 API 费用，而人类专家此前两年未能发现。 这一演示凸显了 AI 在密码分析中日益增强的能力，可能加速发现密码标准中的弱点。它影响了 NIST 后量子标准化时间表，并强调了密码敏捷性的必要性，因为 AI 现在可以发现人类可能遗漏的缺陷。 该攻击并非多项式时间，因此更大密钥仍保持安全，HAWK 也尚未被公开撤回。值得注意的是，同一 AI 还改进了对七轮 AES-128 的攻击，但完整 AES-128 为 10 轮，因此生产系统不受影响。

## [GitHub 推出堆叠拉取请求公开预览版](https://github.blog/changelog/2026-07-30-stacked-pull-requests-are-now-in-public-preview/) ⭐️ 8.0/10

GitHub 宣布了堆叠拉取请求（stacked pull requests）功能的公开预览版，开发者可以将大型更改分解为一系列有序的、相互依赖的小型拉取请求，这些请求可以独立审查和合并。 这是 GitHub 多年来最大的工作流程变革之一，通过鼓励更小、更集中的更改，有望提高代码审查质量并加快开发周期。 该功能包括一个 GitHub CLI 扩展和用于管理堆叠的新 UI，但一些用户报告了问题，例如合并全部功能损坏以及在使用压缩合并时需要重新审批。

hackernews · tomzorz · 7月30日 16:26 · [社区讨论](https://news.ycombinator.com/item?id=49112232)

**背景**: 堆叠拉取请求（也称为 stacked diffs）将大型代码更改分解为一系列较小的、相互依赖的拉取请求，这些请求可以独立审查。这与传统的功能分支工作流形成对比，后者所有更改都在一个大型 PR 中。这种方法在一些开发者社区中很受欢迎，因为它可以实现更聚焦的审查和更快的反馈循环。
